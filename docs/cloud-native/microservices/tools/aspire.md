# Aspire

## 📕 Articles

- [What is Aspire?](https://aspire.dev/get-started/what-is-aspire/) - Official explanation of Aspire as a code-first orchestration and observability layer for distributed applications, including AppHost, service discovery, dashboards, deployment, and multi-language workloads.
- [Build your first Aspire app](https://aspire.dev/get-started/first-app/) - Guided introduction to creating an AppHost, adding projects and infrastructure resources, running the application locally, and inspecting it through the dashboard.
- [AppHost](https://aspire.dev/get-started/app-host/) - Deep dive into the application model where services, databases, containers, dependencies, references, health checks, and configuration are composed in code.
- [Service discovery](https://aspire.dev/fundamentals/service-discovery/) - Explains how Aspire wires service names and endpoints so local development and deployment can use the same application code without hard-coded addresses.
- [Deployment](https://aspire.dev/deployment/) - Practical overview of deploying an Aspire application model to containers, Kubernetes, cloud platforms, and existing infrastructure workflows.
